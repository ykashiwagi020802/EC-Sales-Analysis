# EC売上データ分析 | EC Sales Analysis

**Pythonを活用したデータ整理・集計自動化・レポート作成のポートフォリオ**

## このプロジェクトでできること

Excel・CSVなどに保存されたデータを整理し、集計結果をグラフやレポートとして出力する仕組みを構築したサンプルプロジェクトです。

ECサイトの注文・顧客・商品データを使用し、2026年4月〜9月の売上分析を行いました。

### 対応できる業務の例

- **データ整理：** CSVデータの結合、欠損値・重複・異常値の確認
- **集計作業：** 月別・商品別・媒体別の売上集計
- **レポート作成：** グラフ付きPDFや集計CSVの出力
- **品質管理：** 異常データの検出、処理方針の記録、集計結果の検証
- **定型業務の効率化：** Pythonによる集計・レポート出力処理の再実行

### 想定する活用場面

- ECサイトの売上データの整理・分析
- 毎月の営業実績・販売実績の集計
- 複数CSVファイルの統合とデータチェック
- 定期的な集計表・グラフの作成

| 成果物 | 内容 |
|---|---|
| 集計CSV | 月別・商品別・媒体別の売上集計 |

| データ品質レポート | 異常データと処理方針の記録 |

## 3. 集計方法

### 売上金額

売上は次の式で計算しました。

**売上金額 = 数量 × 単価 − 明細割引**

- 注文ステータスが `completed` または `Complete` の注文を対象とする
- キャンセル・返品・未完了の注文は除外する
- 配送料は商品売上に含めず、別途集計する
- 対象期間外の注文は分析から除外する

### リピート率

同一顧客が有効な完了注文を2件以上行った場合をリピート顧客と定義しました。

**リピート率 = リピート顧客数 ÷ 購入顧客数 × 100**

同じ注文IDに複数の商品明細が存在する場合も、注文数は1件として扱います。

分析結果は **55人 ÷ 97人 = 約56.7%** でした。

## 4. データ品質管理

分析前に、各CSVファイルの整合性を検証しました。

| 検証項目 | 対応方針 |
|---|---|
| 数量・単価の不正値 | 該当する明細を集計から除外 |
| 明細IDの重複 | 重複を確認し、二重計上を防止 |
| 注文マスタに存在しない注文ID | 該当注文を除外 |
| 注文情報の矛盾 | 集計から除外 |
| 注文日の欠損 | 月別集計から除外し、集計可能な他の分析には保持 |
| 顧客マスタに存在しない顧客ID | 不明な顧客として扱う |
| 商品マスタに存在しない商品ID | 商品IDを保持して売上を集計 |
| 対象期間外の注文 | 集計から除外 |

検証結果と処理方針は `data_quality_report.csv` に出力しています。
### データ品質レポートの自動生成・検証

データ品質上の問題を検出し、以下の項目を自動生成しています。

| 項目 | 内容 |
|---|---|
| `issue_type` | 異常データの種類 |
| `affected_rows` | 該当する異常データの行数 |
| `affected_orders` | 影響を受ける注文数 |
| `action_taken` | 処理方針（`exclude`、`partial_exclusion`、`retained`） |
| `impact` | 分析結果への影響 |
| `該当id` | 該当する注文ID |

処理方針は異常の種類や注文ステータスに基づいて自動判定しています。

また、生成した `data_quality_report.csv` を再読み込みし、必要な列の存在、欠損値、重複行、処理区分の妥当性を `assert` によって検証しています。

今回のデータでは、データ品質レポートは12件、影響行数の合計は15行となり、検証を通過しました。

## 8. 実行方法

### ① 必要なライブラリをインストール

Python 3.11環境で、以下を実行します。

```bash
pip install -r requirements.txt
```

### ② データを配置

4つの入力CSVファイルを `data/` フォルダに配置します。

### ③ JupyterLabを起動

プロジェクトフォルダで以下を実行します。

```bash
jupyter lab
```

### ④ Notebookを実行

`EC_Sales_Analysis.ipynb` を開き、先頭から順にすべてのセルを実行します。

分析結果は `output/` フォルダに保存されます。
